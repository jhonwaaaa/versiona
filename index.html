Preguntas frecuentes

¿PassHouse ya tiene todas las funciones disponibles?

No. Se presenta como un proyecto en validación. El PMV propuesto incluye registro de viviendas, ambientes, fotografías, documentos e historial cronológico básico.

¿El checklist reemplaza una revisión profesional?

No. Es una guía para conservar antecedentes. Antes de intervenir tuberías, instalaciones eléctricas o estructuras, se recomienda una evaluación técnica cuando corresponda.

¿Qué recibiré al registrarme?

Un checklist educativo que se abre en esta misma web una vez que el envío de datos se haya confirmado. No se remite automáticamente por correo.
